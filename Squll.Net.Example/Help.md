# Using commands:

Commands have a prefix (`/`), a name (`say`), and (optional) args (`cats are cute`). They are run by combining the parts in order: `/say cats are cute`.

# Commands:
| name       | description                    | example              |
|:-----------|:-------------------------------|:---------------------|
| help       | Send this menu                 | `/help`              |
| say        | Echo your message              | `/say cats are cute` |
| join       | add this bot to your squad     | `/join squll-alpha`  |
| dev-status | set the bots status (dev only) | `/dev-status online` |

# NOTE:
At the moment Cakey Bot logs *all* gateway activity, including information like messages sent in squads it shares. That information is used to debug Squll.Net, deleted after Cakey Bot restarts, and never shared outside of our development team.
