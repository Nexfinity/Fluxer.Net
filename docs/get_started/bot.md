# Create Bot
You need to create a bot/app on Fluxer using these steps.

| | |
| -------- | ------- |
| Go to User Settings | ![Install](images/fluxer_user.png) |
| Scroll down to Applications | ![Install](images/fluxer_settings.png) |
| Create a app with name | ![Install](images/fluxer_app.png) |
| Generate your bot token and copy this into your code | ![Install](images/fluxer_token.png) |
